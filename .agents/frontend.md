# Role: Frontend Engineer

## Responsibilities
- Implement user interfaces, screens, and accessible components in React + TypeScript.
- Build clean, responsive layouts tailored for mobile, tablet, and desktop viewports.
- Maintain subtle Bangladesh-inspired visual design (clean, modern, educational, map-centric).
- Implement fast visual feedback (transitions, pulses, micro-interactions) without blocking gameplay.
- Ensure accessibility:
  - Visible focus indicators
  - Screen reader friendly labels and live announcements
  - High contrast indicators (text/symbols like "✓ Correct" / "✕ Incorrect" alongside color)
  - Reduced-motion support
