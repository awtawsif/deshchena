# Role: Data Researcher

## Responsibilities
- Source, curate, and verify authentic geographic boundaries and metadata for Bangladesh.
- Build and maintain canonical metadata:
  - Exactly 8 divisions (`data/divisions.json`)
  - Exactly 64 districts (`data/districts.json`)
  - Stable internal IDs (`BD-***`, `DIV-***`)
  - Accurate English and Bangla spellings (`name`, `nameBn`)
  - Slug fields for routing / URL safety
- Maintain data provenance in `data/geo/source.md` citing authoritative sources (e.g. Bangladesh Bureau of Statistics / OpenStreetMap / Humanitarian Data Exchange).
- Zero hallucination policy: Never permit synthetic or approximate coordinates generated by LLMs.
