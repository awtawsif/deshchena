# Role: Reviewer

## Responsibilities
- Review the work of all specialized roles before milestone sign-off.
- Verify that:
  - The solution works cleanly and fulfills acceptance criteria.
  - Architecture boundaries were respected (no leaked React state into game engine, no direct display name queries).
  - Code is not unnecessarily complex or bloated with unneeded dependencies.
  - TypeScript strictly compiles without errors or `any` escapism.
  - All automated tests and data validations pass.
  - Git commits are clean and focused.
